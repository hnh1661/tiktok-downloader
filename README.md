# 틱톡 워터마크 없이 다운로드 사이트

비전공자도 그대로 따라 하면 배포까지 끝낼 수 있도록 정리한 가이드입니다.

## 1. 이 프로젝트가 하는 일

- 사용자가 틱톡 영상 링크를 붙여넣으면
- 서버가 워터마크 없는 다운로드 주소를 찾아오고
- 화면에 5초짜리 광고 대기 화면을 보여준 뒤
- 다운로드 버튼을 눌러 mp4 파일을 저장할 수 있게 해줍니다.

폴더 구성:
```
tiktok-downloader/
  server.js          ← 백엔드 서버 (다운로드 링크 추출 + 프록시 다운로드)
  package.json
  public/
    index.html        ← 화면
    style.css
    script.js
```

## 2. 로컬에서 실행해보기 (내 컴퓨터에서 테스트)

1. [Node.js](https://nodejs.org) 설치 (18버전 이상)
2. 터미널에서 이 폴더로 이동 후:
   ```
   npm install
   npm start
   ```
3. 브라우저에서 `http://localhost:3000` 접속

> 참고: 다운로드 추출은 `tikwm.com`이라는 무료 공개 API를 사용합니다. 회사/학교
> 네트워크나 특정 클라우드 환경에서는 이 주소가 막혀 있을 수 있어요. 그럴 땐
> 가정용 네트워크나 실제 배포 서버에서 다시 확인해보세요.

## 3. 배포하기 (무료로 시작 가능)

정적 페이지가 아니라 서버(백엔드)가 필요한 사이트라서, GitHub Pages 같은
정적 호스팅으로는 안 되고 **Node.js를 실행해주는 호스팅**이 필요합니다.
비전공자에게 가장 쉬운 순서는 이렇습니다.

1. **GitHub에 코드 올리기**: [github.com](https://github.com)에서 새 저장소를
   만들고 이 폴더를 업로드합니다. (GitHub Desktop 앱을 쓰면 마우스 클릭만으로 가능)
2. **Render.com으로 배포** ([render.com](https://render.com), 무료 플랜 있음)
   - "New +" → "Web Service" 선택
   - 방금 올린 GitHub 저장소 연결
   - Build Command: `npm install`
   - Start Command: `npm start`
   - 배포가 끝나면 `https://내사이트이름.onrender.com` 같은 주소가 생깁니다.
3. **내 도메인 연결(선택)**: 도메인을 구입한 곳(가비아, 후이즈 등)에서 Render가
   안내하는 CNAME 값을 등록하면 `내도메인.com`으로 접속 가능합니다.

Render 대신 Railway.app, Fly.io 등도 비슷한 방식으로 사용할 수 있습니다.

## 4. 구글 애드센스 연동하기

1. [google.com/adsense](https://www.google.com/adsense/)에서 계정 신청 → 사이트
   주소(배포된 도메인) 등록
2. 승인 심사에는 보통 며칠~몇 주가 걸립니다. **주의**: 다운로드 전용 사이트는
   "실질적인 자체 콘텐츠가 부족하다"는 이유로 애드센스 승인이 거절되는 경우가
   꽤 있습니다. 승인 확률을 높이려면:
   - 사용 방법, FAQ, 저작권 안내 같은 텍스트 콘텐츠를 페이지에 추가
   - 개인정보처리방침 페이지 추가
   - 방문자가 어느 정도 있는 상태에서 신청
3. 승인되면 구글이 스크립트 코드를 발급해줍니다. 아래 두 파일에 표시된
   주석 위치에 그대로 붙여넣으면 됩니다.
   - `public/index.html`의 `<head>` 안 (전체 사이트 광고 스크립트)
   - `public/index.html`의 `id="ad-slot"` 위 (실제 광고 노출 영역)

### ⚠️ 꼭 지켜야 할 정책 사항

- **광고를 강제로 클릭하게 만들면 안 됩니다.** "광고를 클릭해야 다운로드 가능"
  같은 구조는 애드센스 정책 위반(부정 클릭 유도)으로 **계정 정지** 사유입니다.
  이 프로젝트는 클릭이 아니라 **일정 시간 대기(카운트다운)** 후 다운로드 버튼이
  열리는 방식으로 만들어져 있어서 안전합니다. (`script.js`의
  `COUNTDOWN_SECONDS` 값으로 대기 시간 조절 가능)
- 애드센스 승인이 어렵거나 늦어지면, 이런 다운로드 사이트를 잘 받아주는
  대체 광고 네트워크(Adsterra, PropellerAds, Monetag 등)를 먼저 쓰고 나중에
  애드센스로 전환하는 것도 실전에서 많이 쓰는 방법입니다.

## 5. 저작권 · 법적 유의사항 (중요)

- 이 서비스는 타인의 영상을 재배포/재게시하는 용도가 아니라 **개인적 시청·백업
  목적의 다운로드 도구**로 안내해야 합니다. 이용약관·저작권 안내 문구를
  꼭 눈에 띄게 넣어주세요 (기본 템플릿에 문구 포함되어 있습니다).
- 틱톡 자체 이용약관상 제3자 다운로드 도구 사용은 회색지대이며, 국가/상황에 따라
  법적 리스크가 달라질 수 있습니다. 상업적으로 키울 계획이라면 저작권 관련하여
  변호사 상담을 받아보시는 걸 권장합니다. (본 안내는 법률 자문이 아닙니다.)

## 6. 유지보수 참고사항

- 다운로드 추출은 `server.js`의 `fetchFromTikwm()` 함수 하나에 모여 있습니다.
  틱톡이 구조를 바꿔서 갑자기 다운로드가 안 되면, 이 함수만 다른 API로
  교체하면 됩니다 (대안: RapidAPI의 TikTok Downloader 계열 API들).
- 무료 API는 트래픽이 많아지면 요청을 막을 수 있어서, 방문자가 늘어나면 유료
  API(RapidAPI 등)로 전환하는 것을 고려하세요.
